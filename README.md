# 🧘‍♀️ Aarogya – AI-Powered Fitness App

> **An AI-driven fitness coach that helps users train smarter, improve workout form, eat better, and stay consistent.**

---

## 🚀 What is Aarogya?

Aarogya is an **AI-powered Android fitness companion** that combines **real-time pose correction, personalized workouts, nutrition insights, gamification, and wearable integration** into a single platform.

It addresses common fitness challenges such as:

* Improper workout posture and form
* Lack of personalized training
* Difficulty maintaining nutrition
* Limited access to affordable fitness guidance
* Lack of motivation and progress tracking

---

## ⚙️ How Does It Work?

### 🤖 AI-Powered Pose Correction

Uses **MoveNet, TensorFlow Lite, MediaPipe, and OpenCV** to detect body landmarks and analyze exercise movements in real time.

```text
Camera
   ↓
Pose Detection
   ↓
Body Keypoints
   ↓
Movement Analysis
   ↓
Form Feedback
```

### 💪 Personalized Fitness

User goals, activity, and progress are used to provide personalized workout recommendations.

### 🥗 Nutrition Insights

Analyzes nutrition and activity data to provide meal and macronutrient recommendations.

### 🔥 Gamification

Challenges, leaderboards, progress tracking, and rewards encourage users to maintain consistency.

### ⌚ Wearable Integration

Integrates with **Fitbit and Wear OS** to track activity metrics such as steps, heart rate, and calories.

### 🛠️ Tech Stack

| Layer               | Technologies             |
| ------------------- | ------------------------ |
| **Mobile**          | Kotlin, Jetpack Compose  |
| **AI / ML**         | TensorFlow Lite, MoveNet |
| **Computer Vision** | OpenCV, MediaPipe        |
| **Backend**         | FastAPI, Firebase        |
| **Database**        | Room                     |
| **Wearables**       | Fitbit, Wear OS APIs     |
